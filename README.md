# openfang

> Open-Source Agent Operating System built in Typescript,Firecrawl
> 
OpenFang is a production-grade Agent Operating System (Agent OS) designed to run autonomous AI agents that work continuously on your behalf. Unlike traditional chatbot frameworks, OpenFang enables agents to operate independently, execute scheduled tasks, build knowledge, automate workflows, and communicate across multiple platforms.

## 🏗️ Architecture

OpenFang is designed around several core components:

### Hands
Autonomous capability packages that perform specialized tasks on schedules.

Examples include:

- Researcher
- Browser
- orchestor
- Lead Generator
- Collector
- Predictor
- Content Clipper
- Social Media Automation

### Agents
Pre-built and custom AI agents that interact with users, tools, and workflows.

### Memory
Persistent memory system powered by SQLite and vector embeddings.

### Tools
Built-in tools for:

- Web Search
- Browser Automation
- Image Generation
- Knowledge Graphs
- File Operations
- API Integrations

### Channels
Connect agents to multiple platforms simultaneously.
